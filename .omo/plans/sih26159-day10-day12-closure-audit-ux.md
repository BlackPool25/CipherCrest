# sih26159-day10-day12-closure-audit-ux - Work Plan

## TL;DR (For humans)

**What you'll get:** By Day12 you run one command `docker run -p 8000:8000` and get the whole product: a light, projector-readable dashboard where you can customize any pcap security detail, send it, watch families stream in one by one, click any family for its issues, and browse history. Behind it the system proves every number honestly — from TCP reassembly with tshark parity to calibrated risk and anomaly scores — so the final report is 8/8 honest, not theater.

**Why this approach:** Single port 8000 keeps the mental model to one healthcheck and no CORS; core demo image is always available and the mail lab is an optional profile so offline and live both work. Machine learning is reduced to five honest features with leave-one-family-out testing so it cannot memorize the ten families, and the dashboard uses a single indigo accent on a light canvas so judges can read it on a projector and it works air-gapped with self-hosted fonts.

**What it will NOT do:** No heavy AI model or torch in the lean image, no isotonic calibration on tiny data, no raw JA4 fingerprint as a feature, no second dashboard port, and no baking of x86 wheels that break on Apple Silicon. The gateway milter and full mail interception remain a stretch demo, not the graded core.

**Effort:** Large (13 todos +4 verifiers, 4 waves, ~22h wall, 4-agent parallel, 2h human-agnostic)
**Risk:** Medium — p/n 2.8 until TOP5 lands and Docker multi-arch image 650MB need BuildKit; mitigated by LOFAM leakage gap gate and per-arch pip install
